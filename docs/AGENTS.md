# docs/

## Purpose

Durable internals. This folder explains *why the port behaves as it does* and *what upstream can
do*. User-facing material stays in `README.md`; working rules stay in AGENTS.md files.

## Ownership

- `ARCHITECTURE.md` — the upstream-to-here map plus "invariants worth remembering". The
  authoritative statement of engine behavior and of every intentional divergence.
- `capability-inventory.md` — a one-time survey of the **upstream** generator's parameter surface,
  animations, export formats, credits, and repo layout, written before the port existed.
- `img/` — the three README showcase PNGs, produced by `scripts/make-showcase.mjs`.

## Local Contracts

- **`ARCHITECTURE.md` is a contract, not notes.** `src/engine/` edits are governed by it and
  `CONTRIBUTING.md` orders contributors to read it first. Any behavior change that alters a mapped
  file or an invariant updates this doc in the same pass; a divergence that turns out to be
  deliberate gets recorded here rather than left in a commit message.
- **It is known to be incomplete.** Its map covers `src/engine/` only and does not name
  `src/index.js`, `src/character.js`, or the crop/extract methods that back `get_animation`,
  `get_preview`, and the showcase. Extend the map rather than working around it.
- **`capability-inventory.md` describes upstream, not this repo.** Treat it as background evidence
  for fidelity questions, never as a specification of what this server does. It is not generated by
  any script here, carries no date, version, or upstream revision, and cannot be refreshed by a
  command — so its counts and line citations may predate the current pack. Verify against the live
  clone before relying on one.
- **No machine-specific absolute paths in new docs.** `capability-inventory.md:3` hard-codes a
  personal clone path; that is a wart of a captured snapshot, not a convention to copy. `docs/` is
  inside `package.json` `files` and ships to users.
- **`img/` is generated — never hand-edit or hand-place those PNGs.** Regenerate with
  `npm run showcase`. They are deliberately committed (tracked, `*.png binary` in `.gitattributes`)
  because the README embeds them, and they are stale the moment rendering changes.
- **Duplicate facts get one owner.** Sheet geometry, the row/frame table, the tool table, and the
  credits duty currently appear in `README.md`, `CHANGELOG.md`, and both files here. Add a fact to
  exactly one place and link to it.

## Work Guidance

- Prefer a table with `upstream file -> local file` rows over prose when describing the port.
- State divergence at the point of decision: what upstream does, what we do, why.
- When a doc claim and the code disagree, the code is the fact and the doc is the bug — fix the doc
  and say so in the report.

## Verification

None. No check reads these files; accuracy is maintained by the DOX pass and by CI only indirectly.
